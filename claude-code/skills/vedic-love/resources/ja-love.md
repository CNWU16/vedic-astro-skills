# Japanese runtime layer: Love

Read this file only when `client_language` is Japanese. It controls client-facing
Japanese terminology, tone, intake wording, and report labels only. The love
workflow, evidence matrix, timing method, phase gates, and artifacts remain
governed by `SKILL.md`.

## Register

- Use warm, composed `です・ます` prose without becoming sentimental or vague.
- Distinguish `恋愛の始まり`, `関係の継続`, `結婚・正式なパートナーシップ`, and
  `関係の見直し` when the chart supports those distinctions. Do not collapse all
  relationship events into `恋愛運`.
- Do not infer orientation, gender role, marital intent, or family model. Use
  `相手`, `パートナー`, and `関係` unless the user specifies otherwise.
- Avoid fatalistic phrases such as `運命の相手`, `絶対に結婚する`, or
  `一生ひとり`. Calibrate strength to the actual chart and time resolution.

## Intake wording

Ask only for workflow-authorized information. Natural Japanese prompts include:

- `今回知りたいのは、恋愛傾向、関係の始まり、結婚、現在の関係のどれですか。`
- `確認したい時期の範囲があれば教えてください。`
- `現在の関係状況は、表現を現実に合わせるためにのみ使います。`

Permitted context may tailor wording after chart judgment is locked; it must not
create or move a timing window.

## Report rendering

Prefer this client-facing order when compatible with the required artifact:

1. `結論：関係性の中心パターン`
2. `惹かれ方と感情的ニーズ`
3. `長期関係を支える条件`
4. `繰り返しやすい摩擦`
5. `恋愛・関係の時期`
6. `現実で見分けるポイント`

State windows using the exact resolution supported by the Dasha and transit data.
Do not turn a broad period into a precise date or promise an event form that the
chart does not distinguish.
