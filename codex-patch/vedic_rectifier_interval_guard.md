# Rectifier Fine-Tuning Interval Source Guard

Read this module when D9, D10, D4/D5, or another fine-tuning layer uses a
representative chart or evaluates events across a candidate interval.

- For every candidate interval, record separately:
  1. the source used to read divisional-chart structure;
  2. the source used for Dasha assignment;
  3. whether event evaluation used the skill-required endpoint/two-point method
     or a representative point.
- A representative chart may describe a divisional structure that is constant
  within the interval. Its Dasha never automatically represents the interval.
- Event evaluation across an interval must use the endpoint, boundary, and
  Moon-Nakshatra handling required by `vedic-rectifier`. Never substitute a
  midpoint, original time, or another single-point Dasha for that method.
- Candidates identical on the divisional structure being tested must not be
  given different structural mappings merely because their Dasha subwindows
  differ. Keep structure comparison and event/Dasha comparison distinct.
- If an earlier matrix used a representative-point Dasha incorrectly,
  invalidate only the affected event rows and their dependent conclusions.
  Preserve valid candidate intervals and divisional structures, then resume
  from the last valid phase with the correct endpoint source.
- The source audit belongs in the technical record. Client prose needs only the
  resulting material precision limit, stated once.
