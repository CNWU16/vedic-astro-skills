# Prashna 判读单写作指引

> **用途**：Phase 5 写判读单时，怎样照着盘、用占星师的口吻把事情讲清楚。
> **权限**：本文件只管怎么讲，**不计分、不改档**。倾向由判定脚本定好（`prashna_verdict.md`，`judgment-rubric.md`）；
> 这里的宫义、星义、星座性质只用来叙述，不进账本，不能把偏不成讲成偏成，也不能反过来。

---

## 1. 口吻与篇幅

- 用占星师看盘的口吻：先指出盘上的东西（哪颗星、在哪一宫、什么状态），再讲古书怎么看，最后落到提问人的现实里。
- 可以有古典术语感：Lagna（上升）、Bhava（宫）、Graha（行星）、Drishti（照射）、Kendra（角宫）、Trikona（三方宫）、
  Neecha（落陷）、Chara／Sthira（动座／固定座）、Seershodaya（头升座）等，以及宫的外名、内名（`house-meanings.md` 第 2 节）。
  **每个术语第一次出现，紧跟一句白话**，不让读者卡住。
- 用自己的话写，句式要有变化。不套固定句式，不逐项填空；同一类题两次判读，读起来不该像同一篇换了几个字。
- 每个小节写 2–4 段，每段都紧扣一个或几个盘面事实。给用户看的部分（标题到“现在能做什么”）一般 3,000–5,000 字；
  账本条目少的题不硬撑，但每个小节都要有内容。
- 不恐吓、不宿命：不提死亡与寿数；第八宫按问题读（`house-meanings.md` 第 7 节）——问私下时是暗处，没点到时讲变数、阻碍；土星讲“忧劳、负担、迟滞”，不讲病死。
- 不谈输入精度：不写“输入敏感”“时间再准一点会更清楚”之类；核对区的输入提示不搬进正文。
- 不出现判词和档名（成／悬／不成、能成、成不了、很难成、一定、注定、没希望、偏成、持平、偏不成），不出现 `rule_id` 和英文状态码。

## 2. 含义从哪里来

叙述里每一句“这代表什么”，只能取下面六类来源；没有出处的含义不写。

|---|---|---|
| 成事账里的古法原文 | 判断依据，计分 | `prashna_verdict.md` 成事账 |
| 宫义 | 这一宫管什么（三层：即时盘专用、本命经典、白话），外名内名 | `house-meanings.md` 第 2 节；`M-XIV.24` 上升＝提问人 |
| 星义 | 这颗星主管什么人和事，所问需要它还是不需要 | `house-meanings.md` 第 3、7 节 |
| 星座性质 | 这个星座是什么样的座 | `house-meanings.md` 第 4 节 |
| 强弱 | 这颗星有没有力 | `prashna_verdict.md` 能力层与“宫主能力与连接”表；`M-XIV.32` 有力则所主之事显、无力则徒有其名（土星相反） |
| 吉凶标签 | 对这一宫是助力还是压力 | 宫表标签（`standard-layer.md` §2.1），按问题读（`house-meanings.md` 第 7 节） |

## 3. 怎么写“盘面怎么说”

**成事账是故事的骨架**：故事讲的就是判定定档的理由。成事账里每条计分规则都要讲到，按推的、拖的、没有方向的
分组；故事的走向就是合计的方向。语境不合、不入账的条目不当依据讲。背景事实只能挂在某条账本条目旁边作补充，不单独成段推出结论。
写的时候发现取象错了（关键词、事项宫、行动者），改取象单重跑判定，再按新结论写；不在故事里改口，也不让故事和档位各说各的。

1. **小标题用盘面特征命名**，如“上升双子：头升之座，托底不足”“第七宫：土星的目光压着”，不用“你这一侧”之类的空标题。
2. **能力、意愿、环境三层都讲到**，顺序可以按这张盘的重点调整：
   - **能力**（`judgment-rubric.md` §5）：指标星（事项宫主）有没有能力履行。读核对区能力层一行，讲折损项、救应与按需减项；
     "能力打折"讲清折在哪、谁在救；"严重受损"讲清为什么判不行。有力只说明有能力，不说事情一定成。
   - **意愿：指标星在做什么**（`judgment-rubric.md` §6），五步：
     1. 它是谁：这颗星本身主什么（`house-meanings.md` 第 3 节），它管哪几宫；
     2. 在哪做事：落宫的宫义（`house-meanings.md` 第 2 节），按问题读（第 7 节）；
     3. 和谁在一起：同宫、照射它的星各是什么、管哪几宫（"从哪里飞来"）、谁强谁弱；逐颗按 `house-meanings.md`
        第 7 节三问讲：带来什么、这题要不要、有没有力送到。所问正需要它时写成"带来……"（例：问主动时 Mars 照
        7 宫主＝带来冲劲），不写成"受压"；
     4. 状态：逆行、燃烧、落陷，讲成"怎么做"（反复、被压住、使不上劲），不单独下结论；
     5. 和提问人有没有桥：按 `house-meanings.md` 第 8 节连接口径（同宫、照射单向即可、互换、互为 4／10 宫、
        征象星串联），写清靠什么连上（经 Mars＝靠行动，经 Venus＝靠情意，经 Mercury＝靠言语）。
     问题里的条件（谁主动、私下或公开等）按核对区限定语的结果讲清成立与否、有多强。
   - **环境**：上升一侧、事项宫一侧的扶压，月亮心境（专题规则用到月亮时照规则讲），以及"几条古法加起来"：
     账本每条讲成一句人话，明写推几份、拖几份、几份没有方向。
3. **每个事实走三步**：盘上是什么 → 古书或宫义星义怎么看 → 放到提问人的现实里可能是什么样子（给一两种常见情形，用“可能”“常见是”，不替用户编细节）。
4. **背景与依据分清**：账本条目用“古书说……”的口气，是判断的依据；背景事实挂在相关账本条目旁边，用“另外”
   “从背景看”的口气，不下结论。
   **背景事实方向与内部档相反时，只能放在“不过”“转机”的位置，并说明它不改变整体判断；不许给它加码。**
5. **标题、简述与正文同向**：读完全文，读者对倾向的感受必须与内部档一致。
6. **你可能会注意到的信号**：用户在问题或追问里点名的组合，以及与指标星同宫、照射它的入旺、本座之星和入旺的
   Moon，单列一小段逐条回答：按出处它怎么读（两层宫义不一致时并列）、在本题里起什么作用、为什么计分或不计分。
   不许只写"背景，不计分"了事。
7. **新标签的写法**：单条证据——"这张盘只有一条古法给出方向"；盘面未给方向——"按原文，这张盘对这一问没有给出
   判据"，给改问建议；能力不足——讲清指标星哪几项受损、为什么没有救应；两说——两种读法各自的走向并列；吉凶相当——讲清哪几条推、
   哪几条拖、什么变化会让它偏向一边。
8. **行动型问题两步讲**（`judgment-rubric.md` §8）：标题与简述各用一句分别答"会不会动"和"事情成不成"，说出是
   哪一问。行动链按
   起意（谁给他勇气）→ 行动（会不会落成动作）→ 指向你 → 落实（能不能有结果）讲；转宫的宫两层宫义都写，例：
   本盘 8 宫既是"阻碍、暗处"，也是"对方的言语"。"有心无力"讲成"想动，但使不上力"，讲清哪颗星受损。
9. **两层读法不同时，先分清是不是同一件事**：同一颗星、同一组连接，在账本与能力、意愿层或行动链里可能读法
   不同。例：问"他会不会主动约我"，Mars 照 7 宫主在行动链里是"带来冲劲"，在 `P-I.3` 账本里按宫表标签记不利；
   Lagna 主与 7 宫主互为 4／10 宫，意愿层算连上，账本的 `M-XVII.16` 只认原文所列的互换、入旺、互照，记"无"。
   正文用三句讲清，不让用户猜：① 这一问拆成哪两件事；② 各看什么、各自结论；③ 合起来对你意味着什么（例："他
   多半会主动约你；见面顺不顺，这张盘偏紧；Mars 给他冲劲，也带来摩擦"）。不让一边盖掉另一边，也不因此改账本或
   改档（`M-XIV.47`：卜卦按所落之处筛象义）。两层在同一件事上说法相反，是拆题错了，回 Phase 2 重拆
   （`question-decomposition.md` 第 2 节），不把两个相反结论交给用户。

## 5. 内容契约

只定讲清什么，不定句式；版式和语气细节由使用方调整。

1. 不用判词给结论：不写“成／悬／不成”和内部档名，也不写“能成”“成不了”“很难成”“一定”“注定”“没希望”这类断语。倾向在故事里讲明白，
   不准模棱两可。
2. 盲读检查：只看标题和简述，读者能分辨偏成、持平、偏不成；读完全文，对倾向的感受也必须与内部档一致。行动型问题：读者能分别说出
   “会不会动”与“事情成不成”两个倾向，前者与行动链一致、后者与内部档一致，不用猜哪句答哪一问。分辨不出或感受相反就重写。
3. 定档的理由就是故事的骨架（§3）；带判断的话都能在核对区成事账里找到对应条目。背景事实（不计分）在核对区列出；与内部档方向相反时，
   只能放在“不过”“转机”的位置并说明它不改变整体判断，不许加码。
4. 含义只取 §2 的六类来源；没有出处的含义不写。
5. 术语可以出现，第一次出现紧跟白话；不出现 `rule_id`、`mixed`、`promise`、`cusp`、`sub-lord`、`Itthasala` 或生产状态码；不能用“混合配置”
   “支持级 B”或“实验候选”代替事件说明。
6. 不给固定句式模板，用自己的话写；篇幅按 §1。
7. 偏成·有阻力、偏不成·有转机：说清阻力或转机具体在哪（对应成事账里的反向条目）。
8. 持平：说清两边各是什么、该看哪个信号；两说时两种走向并列。
9. 偏不成：不下死结论；讲清卡点、现在能做什么、什么变化之后可以再问。
10. 不归咎提问人：卡点讲成条件（如“你这边的准备和时机”），不评判人，不从盘里读性格。考试题即使偏成，也提醒照常准备。
11. 时间：把主时间和最近的触发日合成一句，如“最可能在 X 前后，最近的一个节点是 Y 日”；偏不成不给时间。
12. 不使用极端或宿命化措辞；不谈输入精度。

## 6. 安抚

情感类问题（复合、联系、分手后等）的安抚写在正文里，守六条：

1. 只安抚一次，要具体，引用用户原话；不用“一切都是最好的安排”“时间会治愈一切”“放下才能拥有”“你值得更好的”这类套话。
2. 追问时不重复安抚，除非用户表达了新的情绪。
3. 安抚不改结论。
4. 安慰要有盘面依据：持平只取卡点和最近的触发日；偏不成说明这张盘答不了什么，以及什么现实变化之后可以再问。
5. 操控／打听类问题：一句话说明为什么不判，再给替代问法，不说教。
6. 出现自伤或极端语句：先回应安全，不起盘。

天气条件不满足时写“原文无反面判据”，不写“不会下雨”。

## 8. 写作自检

- [ ] 每个小节都落在具体盘面事实上，有 2–4 段？
- [ ] 每个术语第一次出现都有白话？没有 `rule_id`、状态码、判词和档名？
- [ ] 含义都出自 §2 六类来源？没写 XIV.28–29 与本命方法？
- [ ] 能力、意愿、环境三层都讲到？意愿层按五步讲了指标星在做什么？问题里的条件逐条回答了？
- [ ] 用户点名的组合和显眼的强星，在"你可能会注意到的信号"里逐条回答了？
- [ ] 同宫、照射之星是按"带来什么、这题要不要、有没有力送到"讲的，没有一律写成吉或凶？
- [ ] 行动型问题先讲"会不会动"再讲"能不能成"？别人的动作是从那个人的宫起算的？
- [ ] 两层读法不同时，按三句讲清了是哪两件事、各自结论、合起来的意思？同一件事没有出现两个相反结论？
- [ ] “几条古法加起来”写明了推几份、拖几份、几份没有方向？
- [ ] 背景事实没有和内部档反向加码？语境不合、不入账的条目没有当依据讲？
- [ ] 没有谈输入精度？
- [ ] 标题、简述、全文三者与内部档同向？
- [ ] 用的是自己的话，没有套句式？
