# 校准出题规范（calibration_quiz）

> 何时读：某层（D1 / D9 / D10 / D4 / D5 / 3d Nakshatra 边界）判读为"低"、需要出题时。**出题前必读全文**；换批、解读答案时也按本文件。
> 地位：不替代 SKILL.md 的映射判读表，不新增阶段；每层最多两轮（SKILL.md「每层统一流程」第 8 步）。
> 来源：2026-10-10 据 codex 侧出题规范中文化移植；2026-10-24 按 SKILL.md「判断为主·主纲」改写：原五项检查减为三检，答案回判读表重判、不再按题计分。

## 零、题为什么会分不开

出了题却分不开候选，几乎都是下面几种原因，第三节的七步就是逐条防它们的（其中 1、5、6 是硬检，其余写成注意事项）：

1. **题不是从这张盘推出来的**：套用"某星座稳重、某星座灵活"这类模板，两个候选都说得通（巴纳姆）。
2. **差异是假的**：两个候选在这个领域的盘面其实一样，或被别的行星冲淡了。
3. **选项不对等**：一个选项明显更体面、更"健康"，用户不看盘也会选它。
4. **大多数人都选同一边**：选项反映的是年龄阶段常态或社会期望，跟盘无关。
5. **一题多轴**：把几件事打包成一题，用户只能挑"大体像"的那个（chimiao 式打包题）。
6. **用户答不了**：问自我感、问动机、问没经历过的领域、问"哪个先发生"。
7. **映射是事后贴的**：看了答案或看了 user_context 再决定哪个选项对应哪个候选。

## 一、入场条件

- **先映射，分不出才出题**：当前层的映射判读表、主线判断和反方陈述必须先做完；❌ 禁止跳过判读表直接抛问卷（与全局 CLAUDE.md"先映射、分不出才补问用户辅证"一致）。
- 写明：还没分开的是哪几个候选；每题的答案怎样可能改变判断（至少有一种答案能让某个候选明显更像）。改不了排序的题，不作为定盘题出。
- **能直接问的事实就直接问**：用户还没说过、各候选预期不同的事实（亲属、婚育、怀孕方式、相识方式、配偶职业、专业、病种、出国、换城市或远程工作的次数…）或带日期事件，直接问事实本身，答案进判读表，不必包装成 A/B 题。客观事实问出来还可能成为决定性对立证据。
- 只有当已知时间范围跨过某个候选间的 Dasha 区分点时，才追问月份或日期；没有信息增益的精度不是追问理由。
- user_context.md 只用于两件事：避免问已知的事（已知的直接进判读表）和「领域适用」。❌ 不得用 user_context 决定"候选 → 答案"的映射。

## 二、锁定比较对象

- D1 题比较的是不同的 Lagna 星座。同一个 Lagna 星座下的多个时间段，D1 结构题的映射必须相同（它们在事件/Dasha 矩阵里可以分开）。
- D9、D10 或之后的层，比较的是该层的不同结构。在被测结构上相同的候选，映射必须相同，或都记 0。
- 锁定之后、拿到答案之前，如果候选集或盘面结构变了 → 作废旧锁定，对全部有效候选重新锁定。

## 三、出题七步

### 第 1 步 · 差异清单（只列真差异）

逐个候选读盘（structured_data / time_scan 输出，❌ 禁手推），列出**该层候选间会变**的字段：

```
| # | 差异字段 | 候选X | 候选Y | 生活领域 | 强弱 |
|---|---------|-------|-------|---------|------|
| 1 | 1宫行星  | Saturn | Jupiter | 本人外在作风 | 强 |
```

各层看什么：D1 = Lagna 主及其落宫、各宫宫主、1/4/7/10 宫内行星；D9 = D9 Lagna 主、D9 7宫与 7主、D9 1/7 宫内行星、Venus 与 DK 的 D9 落宫；D10 = D10 Lagna 主、D10 10宫与 10主、D10 1/10 宫内行星、Sun/Saturn/AmK 的 D10 落宫；D4/D5 同理；Nakshatra 边界 = Lagna 所在 Nakshatra 的主星与 pada（同时是 D9 换座点）。

**强弱**：
- **强**：a) 某颗行星在一个候选落角宫（1/4/7/10）、在另一个候选不在；b) 某宫宫主在两候选间换成性质相反的行星（如 Saturn ↔ Jupiter、Mars ↔ Venus），且该宫是用户已经历的领域；c) Lagna 主在两候选间落到生活领域明显不同的宫。
- **弱**：只差尊贵度一档；差异只体现在 Lagna 星座本身的泛性格（"土象稳重 / 风象灵活"）；差异落在用户还没经历的领域；差异被同宫或照射的其他行星冲淡。
- 先用强差异出题。强差异用完才考虑弱差异，且弱差异题要写明混杂与基础率的注意事项。

### 第 2 步 · 对立预测（每条差异写一对）

对每条强差异，写出两个候选各自的**日常默认**，再写两句"为何不会是对方那样"：

```
差异1：X 下 1宫有 Saturn；Y 下 1宫有 Jupiter
  X 预测：……
  Y 预测：……
  为何 X 下不太会是 Y 的样子：……
  为何 Y 下不太会是 X 的样子：……
```

- 两个预测在**同一领域、同一颗粒度**（都说"第一印象"，或都说"和配偶起分歧时的反应"），不能一个说性格、一个说事件。
- **可观察**：写做了什么、发生过什么、别人怎么说你、别人怎么对你；不写"内心是什么样的人"。
- **从差异字段推出**：宫的含义按 `event_house_map.md`「核心映射」与「静态事实映射」，行星按其自然征象；❌ 不套星座性格模板。
- 两句"为何不会"写不出来 → 这条差异在生活层没有对立，弃掉，换下一条。
- 映射只由盘面推出；这一步不看 user_context。

### 第 3 步 · 选题型（越客观越好）

按顺序选第一个能承载这对预测的题型：

1. **事实题**：用户能直接答的客观事实 → 直接问，答案进判读表（见第一节）。
2. **经历题**：过去遇到某类情况时，实际怎么做、实际发生了什么。
3. **旁人评价题**：熟悉你的人（家人、同事、朋友）通常怎么说你、怎么对你。比自评稳。
4. **偏好题**：你更喜欢哪种。最容易受社会期望影响，最后才用。

### 第 4 步 · 写成 A / B / 0（或"符合 / 不符合"）

- 题干给一个具体领域或情境，一句话说完；❌ 不出现星座、宫位、行星、候选时间等术语或暗示。
- A、B 分别是两个候选的预测：长度、具体程度相近，都是正常、体面的样子；❌ 不用"总是 / 从不"，不堆形容词。
- 0 = 两个都像、都不像，或看情况。
- 只针对一个候选的独有预测时，可写成"符合 / 不符合 / 说不清"：该候选预测符合，另一候选预测不符合。
- **单轴**：一题只测一个差异；例子可以帮助说明，但不得引入第二个决定。
- **领域适用**：用户没经历过的领域不问（未婚不问配偶，没上过班不问职场权责）。
- ❌ 不用"哪个先发生 / 哪个必须在前 / 哪个不可或缺"人造互斥，除非这个先后本身就是明显的生活差异。
- **A/B 位置轮换**：同一候选在各题里的对应选项要在 A、B 间交替。

### 第 5 步 · 三检与注意（逐题写结论）

**三检（任何一检不过 → 改写或弃）**：
1. **对调检**：把 X、Y 的映射对调，还说得通吗？说得通 = 零区分 → 弃。
2. **单轴检**：一题只测一个差异，没有打包第二个决定（见第 4 步）。
3. **可答检**：用户读一遍，能凭具体记忆或别人的反馈回答吗？需要回忆精确日期、揣测动机、把多种情境平均 → 改得更具体，或弃。

**注意（写一句结论，不一票否决）**：
- **混杂**：对方候选盘里有没有别的因素（同领域其他宫主、同宫星、照射）同样会产出这个选项？有 → 写明，作答后这题的分量相应减轻。
- **基础率**：不看盘随机找同龄人来答，是否明显一边倒（社会期望、年龄阶段常态）？是 → 尽量改写选项；改不了就写明，作答后分量减轻。
- **已知**：答案能从 user_context 或已采集的事实推出来 → 不出题，直接进判读表。

### 第 6 步 · 组批与锁定

- 一批里每题来自不同差异；同一差异、同一现实过程（同一次升职、迁居、关系转折）只出一题。
- 多候选（≥3）：每题至少分开一对候选，允许部分分离（一个候选对其余，其余映射相同或记 0）；整批要让每个存活候选至少被一题单独分出来。❌ 别出想同时分开所有候选的大杂烩题。
- 题数由过了三检的强差异数决定，每轮 3–5 题；❌ 不为凑数出弱题。
- **作答前锁定**：把差异清单、对立预测、三检结论与注意、每题每个候选的 A/B/0 映射写进工作目录 `rectification_quiz.md`（底稿，模板见第七节）。底稿写完再发题；批内 ❌ 不按前几题的答案改后面的题。

### 第 7 步 · 发题

聊天框先报一行底稿概况，再只发题面（不含映射）：

```
出题底稿已写入 rectification_quiz.md：N 条差异 → M 题过三检（弃 K 题），映射作答后公布。

【校准题·第 N 批】每题选 A / B / 0（0 = 两个都像、都不像，或看情况）；答不上直接说，撤题不算。
1. [情境或特质，一句话]
   A. ……
   B. ……
2. ……
```

## 四、反例与正例

**反例（都分不开候选）**：

| 题 | 毛病 | 挂在哪一检／注意 |
|---|---|---|
| 你是外向还是内向？ | 不来自盘面差异，两个候选都能解释；自评不稳 | 对调检 |
| 你更看重事业还是家庭？ | 两个都要，大量选 0；"家庭"更体面 | 基础率（改不了 → 弃） |
| 你更像"稳重踏实"还是"灵活多变"？ | 星座性格模板，且等于把映射告诉了用户 | 第 2 步、第 4 步 |
| 小时候家里管得严、后来离家读书、婚后才安定，符合吗？ | 三件事打包，只能答"大体像" | 第 4 步单轴 |
| 你是先换的工作还是先搬的家？ | 人造先后，把盘面的模糊转嫁给用户 | 第 4 步 |
| （对未婚用户）你的配偶是什么样的人？ | 领域没经历过 | 第 4 步领域适用 |
| 你经历过重大的人生转折吗？ | 不是二选一，人人都有 | 对调检 |

**正例 1（D1，示意）**：候选 X = Capricorn Lagna、Y = Sagittarius Lagna；Saturn 在 Capricorn、Jupiter 在 Sagittarius。

```
差异：X 下 1宫有 Saturn；Y 下 1宫有 Jupiter（强：行星进出角宫）
X 预测：在人前偏拘谨、慢热，第一印象常被说严肃、老成
Y 预测：在人前和气，常被当成可以请教、会给建议的人
为何 X 不像 Y：Saturn 压在 1宫，起手先收着；X 下 Jupiter 落 12宫，不照 1宫
为何 Y 不像 X：Y 下 Saturn 落 2宫，照 4/8/11宫，不照 1宫
题型：旁人评价题
题：第一次见你的人，事后对你的印象更常是：
  A. 挺随和，愿意给人出主意、讲道理
  B. 比较严肃、话不多，熟了才放开
映射：X → B，Y → A
三检：对调（Saturn → 随和？不通）过；单轴 过；可答（凭别人的反馈即可）过
```

**正例 2（D9，示意；已婚用户，D9 矩阵已填完仍差 <2）**：候选 C1 = D9 Aries Lagna（7宫 Libra，7主 Venus）、C2 = D9 Taurus Lagna（7宫 Scorpio，7主 Mars）。

```
差异：D9 7主 C1 = Venus，C2 = Mars（强：7宫宫主性质相反，用户已婚）
C1 预测：配偶处理分歧时偏缓和，先顾气氛再谈
C2 预测：配偶处理分歧时偏直接，当场说开、要结论
混杂注意：Venus 是婚姻自然征象，几分钟内它的 D9 落宫不变 → 两候选相同，不构成混杂也不提供区分；
        但若 C1 的 D9 7宫里另有 Mars 同宫，C1 的"缓和"预测被冲淡 → 这题要弃
题型：经历题
题：你们两个意见不合的时候，对方更常见的做法是：
  A. 直接说出来，当场要个结论
  B. 先缓和一下气氛，过后再商量
映射：C1 → B，C2 → A
```

正例只示范推法；实际取宫、取星、强弱、混杂都以本盘数据为准。

## 五、作答后怎么用

- 作答后把每道有效题的答案作为一条证据写回 SKILL.md 的**映射判读表**（标明"出题作答"），回「每层统一流程」第 2 步对**全部候选**重判；不按题数加分。
- 选 0、缺答、答不上都不是任何候选的支持。
- 有混杂或基础率注意的题，判读时分量减轻并写明。
- 题目答案一般不单独裁决一层；客观事实题的答案若满足"一个候选强烈预言、另一个预言相反"，可以成为决定性对立证据。自评性格题不能单独定一层（chimiao 教训）。
- 答案比例、全 A / 全 B、题数、批量大小本身都不构成确认。

## 六、成批出题、失败与加轮

- 有效性逐题判，除非某个缺陷影响整批；混合批次保留可用的题。
- 区分 0 / 缺答 / 答不上，三者都不是候选支持。
- **答不上就撤题**：用户说某题答不上、或不符合真实生活 → 撤题，不逼选。撤掉的题 = 零信息，不说明该层无法判断。
- 作答后发现某题违反三检（如映射事后才发现可对调）→ 该题作废、不用，在底稿记原因。
- **换新角度，不换说法**：一批后仍 <2 → 回第 1 步，从还没用过的强差异出下一批，或换更客观的题型；❌ 不许换说法重复同一个已失败的差异。
- 替换前一批时，听操作者指示是补充、取代还是重来；❌ 不默默叠加或抹掉旧证据。
- 停止条件：该层判读到高/中；每层已出满两轮仍低（→ SKILL.md「每层统一流程」第 8 步：给最佳估计 + 还缺什么证据，由用户决定）；或操作者叫停。

## 七、反馈、重判与底稿

- 作答后在聊天框公布锁定映射，把每道有效题的答案应用到**全部候选**，不只看领先的两个。
- 回 SKILL.md 跑全候选「反证强制重检」，再按「每层统一流程」重判。直接问出的事实与带日期的答案都进判读表对应行。任何题目都不绕过当前层的计算、两点法与精度上限。
- 题目、映射、用户作答按 vedic-reader「增量回写规则」落盘到 user_context.md。

`rectification_quiz.md` 底稿模板（每批追加一节）：

```
## 第 N 批（层：D1/D9/D10/…；候选：X、Y[、Z]；作答前锁定）

### 差异清单
| # | 差异字段 | X | Y | 生活领域 | 强弱 |

### 逐题
题1 ← 差异#1｜题型：经历/旁人评价/偏好
  X 预测：…   Y 预测：…
  为何 X 不像 Y：…   为何 Y 不像 X：…
  题面：…  A. …  B. …
  映射：X → A，Y → B[，Z → 0]
  三检：对调 过｜单轴 过｜可答 过
  注意：混杂（有/无，理由）｜基础率（是否一边倒）

### 弃题
差异#3：对调检不过（映射对调后同样说得通）

### 作答与重判（作答后追加）
题1：A → X +1｜题2：0 → 不计｜题3：撤题（用户答不上）
本批作答写回判读表后：领先 [X/Y]，置信 [高/中/低] → [定 / 再出一轮 / 两轮仍低，交用户决定]
```
