## 主宫与辅宫：为什么只设一个主宫

一件事挂的宫越多，随便一颗大运／小运主星都越容易"对上"，候选盘就分不开。所以：

1. **只有主宫能给强匹配（✅✅）。** 决定性对立证据的认定照 SKILL 3c 主纲，不另立。
2. **辅宫只作确认**：主宫已对上时辅宫再对上，叙述可写"多处一致"，计分不加；主宫没对上、只对上辅宫 → 最多弱匹配（⚠️），不能单独翻转候选。
3. **同一件事不跨宫叠加**：主宫、辅宫都对上，只按主宫那一条算；不同类的确认（Karaka、相关分盘、Chara 双系统）照主纲判读，不受本条限制。
4. **只计候选之间不同的**：某宫在各候选下指征相同 → 记"无区分"，不进比较。
5. **主宫怎么选**：①这件事是该宫的**主义**而不是次义（10 宫主义是事业，"旅居异国"是次义 → 只作出国的辅宫）；②原文直接点名这件事优先于近义引申；③数据足够时实测更准的优先。

## 静态事实映射（常用示例）

> 用途：rectifier 3c 映射判读表中事实与特质的常用规则示例，不是封闭表。表外事实（怀孕方式、相识方式、配偶职业、专业、出国等）按上方「核心映射」取宫/宫主/Karaka。不论表内表外，判读时写明"候选间变化的字段 → 取宫规则 → 每个候选的预期"，同一规则施于全部候选；对照后才想到的规则标"事后观察"，预登记过的规则才能充当决定性对立证据。
> 判据一律读 structured_data（尊贵度、燃烧、「Graha Drishti」表），❌禁手推。分盘级（D9/D10）用同一行，换成该分盘的宫与宫主。

- **受克** = 与 Saturn/Mars/Rahu/Ketu 同宫或受其 Graha Drishti、落陷、燃烧；宫主另加"落 6/8/12 宫"。**有力** = 入旺或本座、且无受克。
- **判读**（每条事实 × 每个候选）：会随候选变化的指征（宫、宫主、分盘位）符合"支持" → ✅；全部相反 → ❌；其余 → 中性。该行宫与宫主的状态在候选间相同 → 写"无区分"。
- **决定性证据**：仅"可作决定性证据=是"的行，且事实经用户确认、一个候选的指征全部支持而另一个候选全部相反（含自然征象星）→ 可单独裁决这对候选。自然征象星受克与否多半不随候选变化——它支持该事实时，只按上条判读。

## 匹配判定规则

### 强匹配 (✅✅)
```
大运/小运主星 = 事件**主宫**的宫主（辅宫的宫主不算强匹配，见上"主宫与辅宫"）
→ "Venus大运期间结婚，Venus恰好是7宫主" = 强匹配
```

### 中匹配 (✅)
```
大运/小运主星落在事件主宫
→ "Jupiter大运期间结婚，Jupiter落在7宫" = 中匹配

大运/小运主星照射事件主宫（照射 = graha drishti，读「Graha Drishti」表判定，见 SKILL Layer3；❌禁用西占 orb 相位，原「主要相位关系」表已废弃删除）
→ "Jupiter大运期间结婚，Jupiter从1宫照射7宫" = 中匹配

大运/小运主星 = 事件的Karaka
→ "Venus大运期间结婚，Venus是自然婚姻Karaka" = 中匹配
```

### 弱匹配 (⚠️)
```
只对上辅宫（宫主、落宫或照射）
→ 最多到这一档，不能单独翻转候选

大运/小运主星与事件宫位的宫主有相位（相位 = graha drishti，读「Graha Drishti」表，见 SKILL Layer3；不是西占度数相位）
→ 间接关联，可以接受但权重低
```

### 不匹配 (❌)
```
大运/小运主星与事件宫位无任何关联
→ 强烈暗示时间可能偏差（宫主表错了）
```

## 逆推逻辑

当事件不匹配时，用以下逻辑推理时间偏移方向：

```
已知: 
  事件=结婚, 大运主星=Mars
  当前: Mars管L3和L8 → 与7宫无关 → ❌

逆推:
  Mars管什么星座？→ Aries和Scorpio
  哪个Lagna能让Mars管7宫？
    → Lagna=Aries → 7宫=Libra (Venus管) → Mars不管7宫
    → Lagna=Taurus → 7宫=Scorpio → Mars管7宫 ✅
    → Lagna=Libra → 7宫=Aries → Mars管7宫 ✅
  
  如果当前Lagna=Gemini → 需要向Taurus方向移动
  → 时间要往回调（Lagna度数减小）
```
