## 静态事实映射（腿一·常用示例）

> 用途：rectifier 3c「腿一」的常用规则示例，不是封闭表。表外事实（怀孕方式、相识方式、配偶职业、专业、出国等）按上方「核心映射」取宫/宫主/Karaka。不论表内表外，对照用户事实前都先在聊天框预登记"候选间变化的字段 → 取宫规则 → 每个候选的预期"；对照中禁增删、换规则。
> 判据一律读 structured_data（尊贵度、燃烧、「Graha Drishti」表），❌禁手推。分盘级（D9/D10）用同一行，换成该分盘的宫与宫主。

- **受克** = 与 Saturn/Mars/Rahu/Ketu 同宫或受其 Graha Drishti、落陷、燃烧；宫主另加"落 6/8/12 宫"。**有力** = 入旺或本座、且无受克。
- **计分**（每条事实 × 每个候选）：会随候选变化的指征（宫、宫主、分盘位）符合"支持" → ✅；全部相反 → ❌ 扣分；其余 → 中性。该行宫与宫主的状态在候选间相同 → 本条对区分零贡献，不计。
- **淘汰**：仅"可淘汰=是"的行。事实经用户确认 + 该行**全部**指征（含自然征象星）都与"支持"相反 → 淘汰该候选。自然征象星受克与否多半不随候选变化——它支持该事实时，任何候选都不淘汰，只按上条计分。

## 匹配判定规则

### 强匹配 (✅✅)
```
大运/小运主星 = 事件对应宫位的宫主
→ "Venus大运期间结婚，Venus恰好是7宫主" = 强匹配
```

### 中匹配 (✅)
```
大运/小运主星落在事件对应宫位
→ "Jupiter大运期间结婚，Jupiter落在7宫" = 中匹配

大运/小运主星照射事件对应宫位（照射 = graha drishti，读「Graha Drishti」表判定，见 SKILL Layer3；❌禁用西占 orb 相位，原「主要相位关系」表已废弃删除）
→ "Jupiter大运期间结婚，Jupiter从1宫照射7宫" = 中匹配

大运/小运主星 = 事件的Karaka
→ "Venus大运期间结婚，Venus是自然婚姻Karaka" = 中匹配
```

### 弱匹配 (⚠️)
```
大运/小运主星与事件宫位的宫主有相位（相位 = graha drishti，读「Graha Drishti」表，见 SKILL Layer3；不是西占度数相位）
→ 间接关联，可以接受但权重低
```

### 不匹配 (❌)
```
大运/小运主星与事件宫位无任何关联
→ 强烈暗示时间可能偏差（宫主表错了）
```

## 逆推逻辑

当事件不匹配时，用以下逻辑推理时间偏移方向：

```
已知: 
  事件=结婚, 大运主星=Mars
  当前: Mars管L3和L8 → 与7宫无关 → ❌

逆推:
  Mars管什么星座？→ Aries和Scorpio
  哪个Lagna能让Mars管7宫？
    → Lagna=Aries → 7宫=Libra (Venus管) → Mars不管7宫
    → Lagna=Taurus → 7宫=Scorpio → Mars管7宫 ✅
    → Lagna=Libra → 7宫=Aries → Mars管7宫 ✅
  
  如果当前Lagna=Gemini → 需要向Taurus方向移动
  → 时间要往回调（Lagna度数减小）
```
